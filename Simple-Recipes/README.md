# Simple Recipes

A responsive single-page recipe website built with semantic HTML and CSS.

## Features

- Sticky navigation with an accessible recipe dropdown
- Smooth internal bookmark navigation
- Featured recipe and responsive recipe-card grid
- Contact form with subscription checkbox
- Mobile-friendly layout
- Josefin Slab and Montserrat typography

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.
