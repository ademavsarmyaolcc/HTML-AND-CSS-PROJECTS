A little about this project

Made for everyday cooks

Simple Recipes is a student-created recipe collection built around one idea: cooking at home should feel approachable, colorful, and fun. I designed this page to practice semantic HTML, responsive CSS, navigation anchors, and accessible form elements while sharing recipes I would genuinely make on a busy weeknight.

Built with curiosity, good ingredients, and a little extra garlic.
