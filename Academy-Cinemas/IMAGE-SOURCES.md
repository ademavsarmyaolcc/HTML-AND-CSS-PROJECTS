# Academy Cinemas — Image Sources

The project stores image files locally in the `images/` folder. The HTML therefore uses relative paths such as `src="images/ben-hur.jpg"`, while the original source links are documented below.

All image assets were downloaded from **Unsplash** and used as local files so the site still has an `images` folder like the video tutorial.
